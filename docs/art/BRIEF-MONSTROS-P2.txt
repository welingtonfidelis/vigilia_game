BRIEF DE ARTE — MONSTROS DO ABISMO E PENDÊNCIAS DO P2
Jogo: Vigília
Pack atual: Vigília Art Pack 1.4.0
Data: 2026-10-20

Este é o pedido para substituir os monstros que ainda usam o DungeonTileset II (0x72).
O objetivo é ter 18 inimigos normais + 6 chefes no mesmo estilo sombrio do pack 1.4,
sem retrabalho de IDs, quadros ou animações no jogo.

O jogo NÃO tem monstros andando no mapa. Eles aparecem apenas no painel de combate
do Abismo. O painel usa o sprite parado (idle), não usa run, ataque, morte, direção
ou flip. Hoje também não existe retrato separado de monstro: o próprio sprite idle
ocupa o lugar do retrato.

================================================================================
1. COMO O JOGO DESENHA OS MONSTROS HOJE
================================================================================

- Inimigo normal: sprite em 2x no painel.
- Chefe: sprite em 1x no painel.
- Slot do painel: aproximadamente 38 px de largura.
- Animação usada: SOMENTE idle, 4 quadros, ~6 fps.
- Run existe no 0x72, mas NÃO é usado no painel. Pode ser entregue como opcional.
- Ataque, hit e morte NÃO são usados. Não é necessário entregar.
- O painel não vira o sprite para a esquerda/direita.
- Não há retrato de monstro no jogo hoje.

Portanto, para o pack novo:
- Obrigatório: 4 quadros de idle.
- Opcional: 4 quadros de run (ficam prontos para o futuro).
- Não é necessário: ataque, hit, morte, direções, flip, retrato.

================================================================================
4. TAMANHOS E FORMATO DE ENTREGA
================================================================================

INIMIGO NORMAL PEQUENO: 16x16
INIMIGO NORMAL HUMANOIDE: 16x23
CHEFE: 32x36

Todos os quadros do mesmo canvas. PNG-32 RGBA, transparente, 1x, sem sombra
projetada, sem texto, sem glow e sem antialias. Pés na base do quadro.

Spritesheet horizontal:
- 4 quadros de idle: 64x16 / 64x23 / 128x36.
- 4 idle + 4 run: 128x16 / 128x23 / 256x36.
- Run, se entregue, vem depois do idle (frames 4–7).

No manifesto, cada entrada deve ter:
- id: o asset ID da tabela;
- type: "character";
- file: caminho do PNG;
- frameSize: [largura, altura];
- sheetSize, columns, rows, frames;
- animations:
  "idle": { "frames": [0,1,2,3], "fps": 6 }
  "run" (opcional): { "frames": [4,5,6,7], "fps": 10 }

O jogo atual usa somente idle; run fica pronto para o futuro.
Não é necessário JSON separado se o manifesto já trouxer os campos acima.

ID de arquivo sugerido:
- char-monster-esqueleto.png
- char-monster-cavaleiro-salobro.png
- char-boss-guardiao-urnas.png

Mas o ID do manifesto deve ser exatamente:
char/monster/esqueleto
char/monster/cavaleiroSalobro
char/boss/guardiaoUrnas

================================================================================
5. TINT E DIREÇÃO DE ARTE
================================================================================

Os tints da tabela são do 0x72 atual. Se os desenhos novos já tiverem cor própria,
NÃO usar tint: eu removo o tint do jogo. O ideal é cada inimigo/chefe ter sua
própria paleta, silhueta e arma/marca, sem reutilizar a mesma base para vários.

Direção: mesma fantasia sombria do pack 1.4 — silhuetas distintas por ato,
materiais do bioma (ossos, ferro, esporos, água, brasa, alma), pouca saturação.

Não usar:
- ataque, hit ou morte;
- direções ou flip;
- texto, sombra ou glow;
- retrato separado (ver seção 6).

================================================================================
6. RETRATOS DE MONSTROS
================================================================================

Hoje o painel do Abismo NÃO tem retrato de monstro. Ele desenha o sprite idle
dentro de um slot de aproximadamente 38 px.

Se quiser entregar retratos separados mesmo assim:
- o tamanho que encaixa sem mudar o layout é 32x36 (mesmo para normais);
- 48x48 é possível, mas exige ajuste de CSS e não é necessário para o P2;
- retratos 48x84 são dos HERÓIS, não dos monstros.

Para o P2, o pedido principal são os sprites idle. Retratos de monstro ficam
opcionais e para depois.
